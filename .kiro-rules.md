## 🛠️ 7. TOOL EXECUTION & SAFETY BORDERS
When interacting with external environments (CLI, APIs, File System):

1. **Principle of Least Privilege:** Request the minimum permissions necessary.
2. **Destructive Actions:** (e.g., `rm -rf`, dropping databases, overwriting config files) MUST trigger a Human-In-The-Loop (HITL) pause.
3. **API Budgets:** If executing a loop that consumes API credits, establish a max-retry limit (default: 3) before halting.
4. **Read-Before-Write:** The Coder MUST read a file's existing contents before executing an overwrite/replace command.
